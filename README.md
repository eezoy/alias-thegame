# Alias

Игра для компании: объясняй слова, не называя их. Смахни карточку вверх, если команда угадала, и вниз, чтобы пропустить.

## Как установить

1. Откройте вкладку **Releases** справа на странице репозитория (или раздел **Actions → последняя сборка → Artifacts**).
2. Скачайте файл `Alias-1.0.N.apk` на телефон.
3. Откройте его и разрешите установку из этого источника, если Android спросит.

Каждое изменение в ветке `main` автоматически собирает новую версию. Она ставится поверх старой без потери настроек.

## Что внутри

- 7 категорий: лёгкие, средние, сложные, рулетка (всё вперемешку), словосочетания, чёрный юмор и «Мои слова».
- Около 18 000 слов и выражений: быт, еда, животные, работа, кино и мультфильмы, литература, искусство, музыка, наука, история, спорт, бренды, интернет-сленг, 18+. Часть общей лексики отобрана из [Roman-/dicts](https://github.com/Roman-/dicts) (подборки rus_custom, Orange и «Шляпа») с распределением по сложности через частотный словарь.
- От 2 до 6 команд, время раунда 15–120 секунд, игра до 20–100 очков (ползунки с шагом 5).
- Штраф за пропуск и общее последнее слово (включаются в настройках).
- Пауза, исправление итогов раунда, звуковой сигнал в конце.
- Слова не повторяются, пока не выпадет весь словарь.
- «Мои слова»: свои слова можно добавлять прямо в приложении, играть ими отдельно или подмешивать в рулетку.

## Как добавить свои слова

Словари лежат в `app/src/main/assets/words/`:

| Файл | Категория |
|---|---|
| `easy.txt` | Лёгкие |
| `medium.txt` | Средние |
| `hard.txt` | Сложные |
| `phrases.txt` | Словосочетания |
| `dark.txt` | Чёрный юмор |

Одна строка — одно слово. Строки, начинающиеся с `#`, считаются комментариями. Рулетка берёт слова из `easy`, `medium`, `hard` и `dark`. После правки и коммита GitHub сам соберёт новый APK.
